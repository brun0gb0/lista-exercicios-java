# Lista de Exercícios Java

Repositório destinado à lista de exercícios de Programação Orientada a Objetos em Java.

## Exercícios

### Exercício 2 - Estudante
Implementação da classe `Estudante`, com cadastro de notas, cálculo da média, identificação da menor nota e métodos de acesso.

### Exercício 3 - Aprovação
Método que recebe um array de estudantes e retorna somente aqueles que foram aprovados, considerando média mínima 6.

### Exercício 4 - Média ponderada
Sobrecarga do método `calculaMedia`, permitindo calcular a média ponderada utilizando os pesos das cinco notas.

### Exercício 5 - Biblioteca
Implementação das classes `Publicacao`, `Livro` e `Periodico`, utilizando herança e representando as regras de empréstimo e devolução dos livros.

## Branches

Cada exercício possui sua própria branch:

- `exercicio-2`
- `exercicio-3`
- `exercicio-4`
- `exercicio-5`
